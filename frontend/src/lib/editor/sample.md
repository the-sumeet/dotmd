# Welcome to dotmd

dotmd is a **plain markdown** note editor. What you see here is stored as ordinary `.md` text — no proprietary format. Toggle **Markdown** in the top bar to see the source.

## Try it

- Type `/` for block commands
- Select text to get the formatting menu
- Use markdown shortcuts: `#`, `-`, `1.`, `[ ]`, `>`, ` ``` `
